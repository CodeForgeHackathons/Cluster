## 🎯 Как это работает

### БЫЛО (TF-IDF только):
```
Пользователь выбирает: Семья, Июнь, Дождь
                          ↓
Система ищет по запросу: "Места для семьи в июне, погода: дождь"
                          ↓
Результат: Озеро, Винодельня, Парк...
(может быть не очень релевантно для детей в дождь 😞)
```

### СТАЛО (Гибридный поиск):
```
Пользователь выбирает: Семья, Июнь, Дождь
                          ↓
1️⃣  DeepSeek генерирует: 
    "Парки с детскими площадками, театры, музеи, 
     крытые развлечения, безопасный темп"
                          ↓
2️⃣  TF-IDF ищет top-20 мест по этому запросу
                          ↓
3️⃣  DeepSeek переранжирует для семьи в дождь
                          ↓
Результат: Парк, Театр, Музей, Парк2, Кинотеатр...
(идеально для детей в дождь! 🎉)
```

## 💻 Быстрая настройка

### 1. Получить API ключ
```bash
# Перейти на https://platform.deepseek.com/api_keys

```

### 2. Добавить в .env
```bash

```

### 3. Перезапустить приложение
```bash
docker-compose down && docker-compose up -d
```

### 4. Проверить работу
```bash
docker exec cluster_api python scripts/test_hybrid_search.py
```

## 💰 Стоимость

```
DeepSeek Chat Pricing:
- Input:  $0.27 / 1M tokens (~$0.00007 per запрос)
- Output: $1.10 / 1M tokens (~$0.00011 per запрос)

Per маршрут:
- Генерация запроса: ~$0.00015
- Переранжирование: ~$0.00035
- Итого: ~$0.0005 per маршрут

Per месяц (100 маршрутов/день):
- $0.05/день × 30 дней = $1.50/месяц

✅ ДЛЯ ХАКАТОНА: практически БЕСПЛАТНО!
```

## ⚙️ Fallback система

Если DeepSeek недоступен:
- ✅ Приложение будет работать с TF-IDF
- ⚠️  Качество будет ниже (но все равно хорошо)
- 🔧 Автоматический fallback встроен

```python
# Если DeepSeek не доступен:
query = generate_smart_search_query(...)  # Вернет базовый запрос
# или
places = rerank_places_with_deepseek(...)  # Вернет исходный порядок
```

## 📞 Если что-то не работает

### Проблема: "DEEPSEEK_API_KEY not set"
**Решение:** Добавить ключ в `.env` и перезапустить

### Проблема: "DeepSeek chat failed"
**Решение:** Система автоматически fallback'ит на TF-IDF

### Проблема: Маршруты медленно генерируются
**Это норм!** Гибридный поиск требует 1-3 сек (вместо 100ms TF-IDF)
Качество того стоит 😊

### Проблема: Хочу откатиться на TF-IDF
**Решение:** Поменяй в `itinerary_endpoints.py` обратно на `search_places_by_embedding()`
