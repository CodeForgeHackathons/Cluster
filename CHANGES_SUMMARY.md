# 📝 Итоговые изменения

## 🔴 Проблема
DeepSeek **НЕ поддерживает embeddings API** (/v1/embeddings)
- Исходный код ошибочно пытался использовать несуществующий endpoint
- Привело бы к 404 ошибкам при попытке вычислить embeddings

## ✅ Решение
Переконфигурирована система для использования встроенного **локального TF-IDF поиска**.

---

## 📄 Измененные файлы

### 1. `server_app/core/config.py`
**Изменения:**
- ❌ Удалена конфигурация `DEEPSEEK_EMBEDDING_MODEL`
- ❌ Удалена конфигурация `DEEPSEEK_EMBEDDING_DIM`
- ✅ Добавлена `USE_DEEPSEEK_EMBEDDINGS: bool = False`
- ✅ Добавлена `EMBEDDING_SERVICE: str = "local_tfidf"`
- ✅ Добавлена поддержка альтернативных сервисов (`EMBEDDINGS_API_KEY`)

**Почему:** DeepSeek не поддерживает embeddings, поэтому используем локальный TF-IDF по умолчанию.

### 2. `server_app/services/deepseek_service.py`
**Изменения:**
- ❌ Переделана функция `get_embedding()` — теперь возвращает `None`
- ✅ Добавлена функция `call_deepseek_chat()` для будущих фич
- ✅ Обновлены комментарии и логирование

**Почему:** DeepSeek может использоваться только для chat, не для embeddings.

### 3. `server_app/services/place_search_service.py`
**Изменения:**
- ✅ Обновлена документация функции `search_places_by_embedding()`
- ✅ Уточнены комментарии о локальном TF-IDF fallback

**Почему:** Функция всегда использует локальный поиск (embeddings недоступны).

### 4. `server_app/api/v1/endpoints/place_endpoints.py`
**Изменения:**
- ✅ `/places/compute-embeddings` → возвращает `deprecated` статус
- ✅ `/{place_id}/compute-embedding` → возвращает `deprecated` статус
- ✅ Добавлена информация о локальном TF-IDF

**Почему:** Embeddings endpoints больше не работают (DeepSeek не поддерживает).

### 5. `server_app/.env.example`
**Изменения:**
- ❌ Удалена опцию `DEEPSEEK_EMBEDDING_MODEL`
- ✅ Добавлены комментарии о DeepSeek ограничениях
- ✅ Добавлены примеры для OpenAI embeddings

**Почему:** Новые разработчики должны знать о ограничениях.
