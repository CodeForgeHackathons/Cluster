# 📝 Документация структуры проекта (FastAPI + SQLAlchemy)

Данная структура проекта построена по принципу разделения ответственности, что позволяет легко масштабировать приложение и упрощает тестирование.

---

## 📂 Корневая директория (Infrastructure)

- **main.py** — Главная точка входа.  
  Здесь инициализируется экземпляр `FastAPI()`, подключаются роутеры из `api/` и настраиваются Middleware (например, CORS).

- **.env.example** — Шаблон конфигурационного файла.  
  Содержит список всех необходимых переменных окружения (ключи БД, секреты JWT) без реальных значений.

- **alembic.ini** — Конфигурация для системы миграций Alembic.  
  Указывает пути к скриптам и настройки логирования.

- **docker-compose.yml** — Инструкции для Docker.  
  Позволяет одной командой поднять всё окружение (FastAPI, PostgreSQL, Redis и т.д.).

- **requirements.txt** — Список всех зависимостей Python, необходимых для работы проекта.

- **.gitignore** — Список файлов и папок, которые Git должен игнорировать  
  (например, `.venv`, `__pycache__`, реальный `.env`).

---

## 📂 Папка `server_app/` (Core Application)

Это основная папка с кодом вашего приложения.

---

### 1. 📁 `api/` (Транспортный слой)

Отвечает за обработку HTTP-запросов и возвращение ответов.

- **v1/endpoints/** —  
  Файлы с маршрутами (роутерами), разделённые по ресурсам  
  (например: `users.py`, `animals.py`).

- **api.py** —  
  "Сборщик" роутеров. Импортирует все эндпоинты из `v1/` и объединяет их в единый API-роутер.

- **deps.py** —  
  Общие зависимости (Dependencies):  
  - получение сессии БД (`get_db`)  
  - проверка авторизации пользователя  

---

### 2. 📁 `core/` (Настройки и безопасность)

- **config.py** —  
  Класс `Settings` (на базе Pydantic). Загружает данные из `.env` и делает их доступными по всему приложению.

- **security.py** *(опционально)* —  
  Логика:
  - хеширования паролей  
  - генерации JWT-токенов  

---

### 3. 📁 `database/` (Слой работы с БД)

- **session.py** —  
  Настройка подключения к базе данных:  
  - создание `engine`  
  - создание `SessionLocal` для работы с транзакциями  

---

### 4. 📁 `models/` (Модели данных SQLAlchemy)

Здесь описываются таблицы базы данных в виде Python-классов.  
Это то, как данные физически хранятся в БД.

---

### 5. 📁 `schemas/` (Схемы Pydantic / DTO)

Определяют формат данных для:
- входящих запросов (Request)
- исходящих ответов (Response)

Служат "контрактом" между фронтендом и бэкендом, обеспечивая валидацию.

---

### 6. 📁 `alembic/` (Миграции базы данных)

- **versions/** —  
  Папка с автоматически генерируемыми скриптами изменений БД.  
  Позволяет версионировать структуру таблиц как Git-репозиторий.

- **env.py** —  
  Настроечный скрипт, связывающий ваши SQLAlchemy-модели с Alembic для автогенерации миграций.
