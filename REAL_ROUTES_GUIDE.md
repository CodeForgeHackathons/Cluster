# 🛣️ Реальные маршруты по дорогам - Руководство

## 🎯 Что изменилось

**ДО:** Простые линии между точками по прямой  
**ПОСЛЕ:** Реальные маршруты по настоящим дорогам с помощью OSRM

## 🚀 Новые возможности

### 1. **RouteMapWithRouting.vue** - Базовая версия
- Реальные автомобильные маршруты
- Автоматическая прокладка по дорогам
- Цветовая кодировка по дням
- Бесплатный OSRM сервер

### 2. **RouteMapAdvanced.vue** - Расширенная версия
- **3 типа маршрутов:**
  - 🚗 **На машине** - автомобильные дороги
  - 🚶 **Пешком** - пешеходные дорожки
  - 🚴 **На велосипеде** - велосипедные дорожки
- Переключение типов в реальном времени
- Информация о расстоянии и времени

## 🎨 Особенности реализации

### OSRM Routing Engine
- **Сервер:** https://router.project-osrm.org
- **Бесплатно:** Не требует API ключей
- **Надежно:** Работает без регистрации
- **Глобально:** Покрытие по всему миру

### Типы маршрутов
| Профиль | Описание | Скорость | Дороги |
|---------|----------|----------|--------|
| `driving` | Автомобильные маршруты | Быстро | Все дороги |
| `walking` | Пешеходные маршруты | Медленно | Тротуары, дорожки |
| `cycling` | Велосипедные маршруты | Средне | Велодорожки |

### Визуализация
- **Цвета:** Каждый день свой цвет
- **Стиль линий:** 
  - Сплошные для авто
  - Пунктир для пешеходов
- **Толщина:** 4-5px для хорошей видимости

## 🛠️ Технические детали

### Ключевые функции
```javascript
// Создание маршрута
const routingControl = L.Routing.control({
  waypoints: waypoints,
  router: L.Routing.osrmv1({
    serviceUrl: 'https://router.project-osrm.org',
    profile: 'driving' // 'walking' | 'cycling'
  }),
  lineOptions: {
    styles: [{
      color: '#00c2ff',
      weight: 4,
      opacity: 0.8
    }]
  },
  addWaypoints: false,
  createMarker: () => null, // Используем свои маркеры
  show: false // Скрываем панель инструкций
}).addTo(map)
```

### Обработка событий
```javascript
.on('routesfound', (e) => {
  const routes = e.routes
  if (routes && routes[0]) {
    const summary = routes[0].summary
    console.log(`${(summary.totalDistance / 1000).toFixed(1)} км`)
    console.log(`${Math.round(summary.totalTime / 60)} мин`)
  }
})
```
