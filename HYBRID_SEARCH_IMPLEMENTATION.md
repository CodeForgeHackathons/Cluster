- Намного лучше, чем простое "семья в июне"

**Что делает:**

- 🔍 Находит относительно релевантные места

**Почему top-20, а не top-12?**
- TF-IDF может пропустить релевантные места
- Берем с запасом для переранжирования
- DeepSeek выберет лучшие 12 из этих 20

## Полный гибридный поиск

```python
from services.hybrid_search_service import hybrid_search_places

places = hybrid_search_places(
    db=db,
    traveler_type="family",
    start_date="2026-06-15",
    weather_labels=["Дождь", "Облачно"],
    interests="детские парки и театры",  # опционально
    limit=12
)
```

**Это делает все 3 шага автоматически:**
1. ✅ Генерирует умный запрос с DeepSeek
2. ✅ Быстро ищет top-20 с TF-IDF
3. ✅ Переранжирует с DeepSeek

## Как это интегрировано в приложение

### В итинерариях (маршрутах)

```python
# server_app/api/v1/endpoints/itinerary_endpoints.py

@router.post("/itinerary/generate")
def generate_itinerary(payload: ItineraryGenerateRequest, db: Session):
    # 🔄 Гибридный поиск вместо обычного TF-IDF

        db=db,
        traveler_type=payload.travelerType or "family",
        start_date=payload.startDate,
        weather_labels=[w.weatherLabel for w in (payload.weatherByDay or [])],
        limit=12
    )
    
    # Дальше строим маршрут как обычно
    candidates = [_place_to_candidate(p) for p in db_places]
    # ...
```

**Теперь при генерации маршрута:**
- ✅ DeepSeek генерирует умный запрос из профиля
- ✅ TF-IDF быстро находит релевантные места
- ✅ DeepSeek переранжирует для туриста
- ✅ Маршрут строится на основе лучших мест

## Требования

DEEPSEEK_API_KEY=sk-your-key-here

### Что если DeepSeek недоступен?

Система автоматически **fallback'ит** на обычный TF-IDF:

```python
# generate_smart_search_query():
result = call_deepseek_chat(prompt)

if result:
    return result  # ✅ Используем умный запрос
else:
    # Fallback: обычный запрос
    return f"Места для {traveler_desc} в {month_name}"
```

**Система будет работать даже без DeepSeek, но менее оптимально.**

## Стоимость DeepSeek

### Примерные затраты для 100 маршрутов/день:

```
1 маршрут требует:
- 1 запрос для генерации умного запроса (~500 токенов)
- 1 запрос для переранжирования (~1000 токенов)
= ~1500 токенов per маршрут

DeepSeek Chat pricing:
- Input: $0.27 / 1M tokens
- Output: $1.10 / 1M tokens
≈ $0.0005 per маршрут

100 маршрутов/день ≈ $0.05/день ≈ $1.50/месяц

✅ ОЧЕНЬ ДЕШЕВО!
```

## Когда использовать какой?

### TF-IDF поиск:
- ✅ Когда нет интернета
- ✅ Когда DeepSeek недоступен
- ✅ Для быстрых локальных поисков
- ✅ Для демонстраций

### Гибридный поиск:
- ✅ Для production (лучшее качество)
- ✅ Для критичных маршрутов
- ✅ Когда DeepSeek доступен
- ✅ Когда есть интернет
