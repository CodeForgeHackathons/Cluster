📊 АРХИТЕКТУРА ГИБРИДНОГО ПОИСКА
================================================================================

Шаг 1️⃣  DeepSeek генерирует УМНЫЙ запрос
        ├─ Анализирует профиль туриста
        ├─ Учитывает сезон
        ├─ Учитывает погоду
        └─ Генерирует детальный запрос

Шаг 2️⃣  TF-IDF БЫСТРО ищет top-20 мест
        ├─ ⚡ Мгновенно
        ├─ 💰 Бесплатно
        └─ 📊 Механическое совпадение

Шаг 3️⃣  DeepSeek ПЕРЕРАНЖИРУЕТ результаты
        ├─ Анализирует все 20 мест
        ├─ Учитывает все факторы
        └─ Выбирает top-12 оптимальных

ИТОГО:  12 идеально подобранных мест в правильном порядке ✅

📞 ОТЛАДКА ПРОБЛЕМ
================================================================================

Проблема: "DEEPSEEK_API_KEY not set"
Решение:
   1. Добавить ключ в server_app/.env
   2. DEEPSEEK_API_KEY=sk-your-key
   3. Перезапустить приложение

Проблема: "DeepSeek chat failed"
Решение:
   1. Проверить интернет соединение
   2. Проверить API ключ корректный
   3. Система автоматически fallback'ит на TF-IDF

Проблема: Маршруты медленно генерируются
Решение:
   1. Это нормально! (1-3 сек вместо 100ms)
   2. Качество того стоит
   3. Можно добавить кеширование позже

Проблема: Хочу откатиться на TF-IDF
Решение:
   В itinerary_endpoints.py поменять:
   
   ВМЕСТО:
   db_places = hybrid_search_places(...)
   
   НА:
   query = _query_text_from_preferences(...)
   db_places = search_places_by_embedding(...)
