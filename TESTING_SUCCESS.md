```

                            ↓

    (если доступен)
                            ↓

```

## Следующие шаги

### Для включения полного гибридного поиска (с DeepSeek):

1. Получить API ключ на https://platform.deepseek.com/api_keys
2. Пополнить счет в DeepSeek (минимум $5)
3. Добавить ключ в docker-compose.yml:
   ```yaml
   DEEPSEEK_API_KEY: "sk-your-actual-key-here"
   ```
4. Перезапустить контейнер:
   ```bash
   docker-compose restart server
   ```
